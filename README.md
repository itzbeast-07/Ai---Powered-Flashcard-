# AI Flashcard Generator

An AI-powered flashcard generation platform that helps students create interactive flashcards from study material using modern web technologies and machine learning.

---

## Features

- Interactive flashcard UI
- Quiz-based learning experience
- AI-powered flashcard generation
- Responsive frontend design
- Modern React + TypeScript architecture
- Machine Learning integration (in progress)
- Backend API integration (in progress)

---

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- CSS

### Backend (Planned / In Progress)
- Python
- Flask

### AI / ML
- Google Gemini API
- Scikit-learn
